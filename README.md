This is the code base for a website created for the Princeton Hypertension Nephrology Associates (P.H.N.A.) doctor's office in Princeton; for storing patient information & logs. 
Currently, the database only works with B.P. logs as well as radiology logs, but may expand over the coming months.

The purpose for the creation of this website was to transition from P.H.N.A.'s current system of filing patient information on paper to a much more efficient, secure database from
which doctors & medical professionals alike at the office may pull information as they need.

This was made by 3 high school students at The Peddie School, in Hightstown, NJ.
